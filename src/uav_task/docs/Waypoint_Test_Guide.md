# 航点飞行测试程序

本测试程序演示了三个核心组件的集成使用：PX4Communicator、VelocityAPFController和VisualServoController（本测试暂不使用视觉伺服）。

## 🎯 测试目标

验证无人机能够自主完成以下飞行任务：
1. 从地面起飞到1米高度
2. 按序飞行四个航点：(1,0) → (1,1) → (2,1) → (2,2)
3. 在最后一个航点自动降落

## 📋 测试场景详情

### 航点序列
- **起飞点**: (0, 0, 1m) - 从当前位置垂直起飞到1米高度
- **航点1**: (1, 0, 1m) - 向前飞行1米
- **航点2**: (1, 1, 1m) - 向右飞行1米
- **航点3**: (2, 1, 1m) - 向前飞行1米  
- **航点4**: (2, 2, 1m) - 向右飞行1米，形成2x2米的正方形路径
- **降落**: 在航点4自动降落

### 飞行参数（针对测试优化）
- **水平速度**: 最大0.3m/s（保守设置）
- **垂直速度**: 最大0.2m/s
- **位置精度**: 30cm容差
- **悬停时间**: 每个航点悬停2秒

## 🚀 使用方法

### 1. 编译项目
```bash
cd ~/ros2_ws
colcon build --packages-select uav_task
source install/setup.bash
```

### 2. 启动PX4（选择一种方式）

#### 方式A: PX4 SITL仿真
```bash
# 启动PX4 SITL
cd ~/PX4-Autopilot
make px4_sitl gazebo-classic
```

#### 方式B: 真实硬件
确保PX4飞控已连接并运行，使用MicroXRCE-DDS代理：
```bash
MicroXRCEAgent udp4 -p 8888
```

### 3. 启动测试程序
```bash
# 使用launch文件启动（推荐）
ros2 launch uav_task waypoint_flight_test.launch.py

# 或者直接运行
ros2 run uav_task waypoint_flight_test
```

### 4. 监控测试进程
测试程序会输出详细的状态信息，包括：
- 当前测试阶段
- 航点进度
- 位置和速度信息
- 错误和警告信息

## 📊 测试状态机

测试程序包含以下状态：

1. **INITIALIZING** - 初始化阶段（3秒）
2. **ARMING** - 解锁飞机并切换到Offboard模式
3. **TAKING_OFF** - 起飞到目标高度
4. **WAYPOINT_FLIGHT** - 执行航点序列飞行
5. **LANDING** - 自动降落
6. **COMPLETED** - 测试完成
7. **EMERGENCY** - 紧急状态（通信异常等）

## ⚠️ 安全注意事项

### 飞行前检查
- [ ] 确认飞行区域安全，无障碍物
- [ ] 检查电池电量充足
- [ ] 验证GPS信号良好（真实飞行）
- [ ] 确保遥控器处于可接管状态
- [ ] 熟悉紧急停止程序

### 紧急处理
- **手动接管**: 随时可通过遥控器切换飞行模式
- **程序终止**: Ctrl+C停止程序，飞机将进入安全模式
- **紧急降落**: 程序检测到异常会自动降落

## 🔧 配置文件

测试使用专门的配置文件：`config/waypoint_test_config.yaml`

主要参数：
```yaml
position_controller:
  kp_x: 0.6          # 较温和的比例增益
  max_velocity_xy: 0.3  # 保守的速度限制
  position_tolerance: 0.3  # 放宽的位置精度

test_parameters:
  takeoff_height: 1.0     # 起飞高度
  waypoint_hover_time: 2.0  # 悬停时间
```

## 🐛 故障排除

### 常见问题

1. **程序启动失败**
   - 检查是否正确编译和source
   - 确认PX4已启动并连接

2. **无法解锁**
   - 检查PX4预解锁条件
   - 确认GPS状态（真实飞行）
   - 检查安全开关状态

3. **航点不精确**
   - 调整PID参数
   - 检查position_tolerance设置
   - 确认传感器精度

4. **通信超时**
   - 检查ROS话题连接
   - 确认MicroXRCE-DDS代理状态
   - 检查网络连接
